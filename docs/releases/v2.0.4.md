# LyricsX 2.0.4

这是搜索结果信息展示的修复版本，目标系统为 macOS 26 及以上。

## 安装

下载 Release 中的 `LyricsX-2.0.4.zip`，解压后将 `LyricsX.app` 拖到 `/Applications`。已有歌词缓存不会由安装过程改写。

校验：`SHA-256 b927722b2ab37f5cff4349cf4764ffca461f11ac485bccaca09228c79edf5e41`。

本包使用 ad-hoc 签名，首次打开时如被 Gatekeeper 拦截：先在 Finder 中打开一次，然后到“系统设置 → 隐私与安全性”点击“仍要打开”。

## 修复

- 搜索结果中新增“逐字”标签，带逐字时间轴的版本会与“双语”标签一起显示。
- 设置的“歌词来源 → 版本偏好”新增“逐字优先”。开启后，严格匹配的候选中会先选带逐字时间轴的版本，再考虑双语与来源排序。
- 结果原有的来源、行数、首句预览和“使用”操作保持不变。

## 验证

`swift test` 通过 72 项回归测试，覆盖逐字优先开关和偏好持久化；Release 构建会执行严格签名校验。
