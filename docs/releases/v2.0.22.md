# LyricsX 2.0.22

减少不必要的后台唤醒与静态背景处理，并简化动效设置。

- 主窗口的封面模糊改为后台生成的小尺寸位图，重复请求复用内存缓存。窗口缩放请求合并，旧任务不能覆盖新结果；歌词、封面主体及逐字动效不变。
- 悬浮窗鼠标检测改为事件驱动，移除每 80 毫秒运行的定时器。密集鼠标事件合并，窗口移动和缩放也会更新命中状态，保留穿透、控制条与经过隐藏功能。
- 新增可选“智能节能”：系统低电量模式或严重发热时限制悬浮窗为 60 帧，恢复后跟随屏幕。原有选择继续保存，所有动画效果保留。
- 辉光设置使用共享的 30 帧动态预览，仅在可见时播放。关闭辉光后收起 HDR 设置，关闭 HDR 后收起亮度调节；帧率和屏幕诊断归入开发者选项。

## 验证

196 项回归及 3 项原生窗口测试通过。背景生成测试在 2048×1440 布局下输出 384×276 位图；100 次相同请求复用同一图像，首次软件处理约 85 毫秒（包含冷启动开销）。该数据验证缓存与处理规模，不代表整机 GPU、瓦数或续航改善比例。

前一版本的 120/60 帧对比见 [性能记录](https://github.com/wzk112/LyricsX/blob/master/docs/performance/overlay-2.0.21.md)。本次没有可靠的逐应用功耗测量，不承诺具体省电百分比。
