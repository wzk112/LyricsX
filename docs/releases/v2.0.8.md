# LyricsX 2.0.8

维护者：Zikai Wang

修复加载期间切歌后丢失已找到歌词的问题，并改善悬浮窗控制条在浅色背景上的可读性。

## 加载与缓存

- 可靠歌词取得后即写入当前缓存目录，不再等整轮搜索结束。即使还在初次显示等待期，切歌也能保留已经取得的结果。
- 返回歌曲或重启应用时先显示已有结果，继续查找更好的逐字、双语版本。临时结果带有未完成标记，不会被当作最高优先级的最终缓存。
- 最终选择或手动应用后清除临时标记；已有最终缓存、手动选择和偏移编辑不会被迟到的临时写入覆盖。缓存仍使用现有文件路径和 LRCX，保留歌词、翻译及逐字时间。
- 自动搜索中，某来源已找到准确且满足当前逐字、双语偏好的版本，就停止该来源的额外查询；最高优先级来源满足条件时，提前结束整轮搜索。
- 未找到满足条件的版本时仍保留跨语言别名和深入搜索。手动搜索继续展示完整版本，不受自动提前结束条件影响。

## 悬浮窗

- 右上角控制条增加局部深色遮罩、轻微阴影与细描边，未激活图标提高亮度。白色网页和深色桌面上都能看清按钮。
- 遮罩独立于歌词玻璃透明度；跟随歌词的控制条和点击穿透时的独立控制条使用相同样式。系统开启“降低透明度”时使用实色背景。

## 验证

离线回归覆盖切歌返回、首次显示前取消、应用重启、离线恢复、最终升级、手动选择保护、过期写入隔离，以及自动提前结束与手动完整搜索。另检查了浅色、深色背景下两种控制条布局的原生窗口截图。

联网复测 `DaiDaiDaiDaiDaikirai / amala` 与 `雪降り / AiSS & NE1516Hz`，均自动选择酷狗双语逐字版本；本次两首合计约 12.6 秒完成。耗时是当次网络测试结果，随来源服务状态变化。

```sh
swift test
LYRICSX_LIVE_REPORTED_SONGS=1 swift test --filter liveReportedSongsAutomaticallyChooseBilingualWordLyricsWithoutCache
./scripts/build.sh release
```

## 安装

下载 `LyricsX-2.0.8.zip`，解压后将应用拖到 `/Applications` 替换旧版。无需清空歌词缓存。

使用 ad-hoc 签名，没有证书到期日，也没有 Developer ID 公证。首次打开的系统提示与处理方法见 [README](https://github.com/wzk112/LyricsX#安装)。
