# LyricsX 2.0.2

这是针对自动搜索与悬浮窗行为的修复版本，目标系统为 macOS 26 及以上。

## 安装

下载 Release 中的 `LyricsX-2.0.2.zip`，解压后将 `LyricsX.app` 拖到 `/Applications`。已有歌词缓存不会由安装过程改写。

校验：`SHA-256 cd3a59460e2620f8c7a7da488b13ba625b39f5629553ede29ed33077e921e108`。

本包使用 ad-hoc 签名，首次打开时如被 Gatekeeper 拦截：先在 Finder 中打开一次，然后到“系统设置 → 隐私与安全性”点击“仍要打开”。

## 修复

- 新增“严格匹配”开关。默认开启时继续校验歌名、歌手与时长；关闭时，若没有严格结果，会使用歌名完全相同或歌名、歌手相容的同步歌词，处理播放器和歌词源元数据不完整的情况。
- 自动搜索始终优先严格候选、准确歌名歌手的时长回退候选、双语偏好和来源顺序；宽松匹配仅在以上结果都不存在时才使用。
- 悬浮窗仅在歌曲有可显示的、带时间轴的非纯音乐歌词时出现。搜索失败、纯音乐、未填词和空白歌词会自动隐藏，用户的显示开关保持不变，下一首有效歌词会自动显示。
- 悬浮窗位置在拖动结束和窗口移动后同时保存，并在下次启动时恢复；位置会自动限制在当前可见屏幕范围内。

## 验证

`swift test` 通过 71 项回归测试，覆盖严格/宽松候选选择、无歌词自动隐藏和位置恢复；Release 构建会执行严格签名校验。
