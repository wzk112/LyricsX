# LyricsX 2.0.16

维护者：Zikai Wang

悬浮窗改为从顶部深色到底部通透的玻璃渐变。只调整材质，歌词布局、逐字与 HDR、换句动画、控制条和位置记忆继续沿用。

- 使用单层原生 [NSGlassEffectView](https://developer.apple.com/documentation/appkit/nsglasseffectview) 清透玻璃。中央仅混合少量材质，边缘保留较完整的系统折射，避免为降低模糊而一起抹掉反光边缘。
- 顶部较深，向下逐渐减弱遮罩。移除额外的整窗背景模糊和大面积白色泛光，保留后方纹理与颜色，减轻磨砂感。
- 渐变放在玻璃后面，以连续圆角略向内裁切，避免覆盖原生顶部圆角；没有额外绘制外框。
- “设置 → 悬浮窗 → 背景浓度”调整渐变强度，继续使用已有偏好。歌词阴影、控制条的独立对比度遮罩保留。
- 开启系统“降低透明度”时使用实色背景。
- 渐变由持久化原生图层绘制，仅在尺寸或设置改变时更新；没有新增计时器、背景截图采样或逐字刷新任务。窗口缩放时沿用原有歌词宿主。

## 验证

常规回归覆盖歌词、搜索、缓存、窗口高度与顶部锚点、逐字/HDR、悬停隐藏及点击穿透控制。原生材质检查使用独立测试会话，在浅色、深色和彩色条纹背景上检查正文、翻译和内嵌/独立控制条；测试不读取播放器或写入正式歌词缓存。

```sh
swift test --no-parallel
LYRICSX_CONTROL_QA=/tmp/lyricsx-glass-qa swift test --no-parallel --filter renderControlsOverLightAndDarkBackgrounds
./scripts/build.sh release
```

## 安装

下载 `LyricsX-2.0.16.zip`，解压后将 `LyricsX.app` 拖到 `/Applications` 替换旧版。缓存和偏好继续复用。沿用 ad-hoc 签名；首次打开提示的处理方式见 [README](https://github.com/wzk112/LyricsX#安装)。
