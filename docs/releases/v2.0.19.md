# LyricsX 2.0.19

首次启动采用新的悬浮窗默认外观，并修复主窗口切歌后仍停留在上一首歌词位置的问题。

- **默认外观**：Liquid Glass、透明度 26%、磨砂程度 80%。默认开启悬浮窗显示和“鼠标经过时隐藏”；隐藏在锁定后生效，解锁后仍可拖动窗口。
- **保留设置**：已有用户保存的样式、透明度、磨砂和显示开关继续生效，升级不会覆盖个人设置。
- **切歌回到顶部**：歌曲或歌词版本改变时，重新建立该列表的滚动和浏览状态。前奏尚未进入第一句时明确回到顶部，加载缓存歌词或稍后完成搜索时也使用新歌的时间轴定位。
- **跟随与动效**：进入歌词后继续平滑跟随当前句。取消上一首的浏览返回任务，避免旧滚动动画或延迟任务把新歌带回错误位置。主窗口重新显示时恢复当前歌词位置。

## 验证

既有回归测试通过。额外使用独立的原生窗口与测试歌词，检查拖回前奏、缓存文档复用、延迟加载、主窗口重新显示，以及滚动动画途中切歌后的实际列表偏移。不控制真实播放器，也不写入真实歌词缓存。

```sh
swift test --no-parallel
LYRICSX_WINDOW_QA=1 swift test --no-parallel --filter WindowFrameTests
./scripts/build.sh release
```

## 安装

下载 `LyricsX-2.0.19.zip`，解压后将 `LyricsX.app` 拖到 `/Applications` 替换旧版。沿用 ad-hoc 签名；首次打开提示的处理方式见 [README](https://github.com/wzk112/LyricsX#安装)。
