# LyricsX 2.0.7

维护者：Zikai Wang

修复搜索结果有时只剩一个来源、部分逐字版本消失，以及错误地提示所有歌词源都无法连接的问题。

## 修复

- LRCLIB 某条记录的 `duration` 为 `null` 时，不再导致整批结果解析失败；单条坏数据不会丢掉其他记录。搜索页也保留纯文本和纯音乐结果。
- 网易云搜索优先使用现有应用接口，保留一次备用接口尝试；去掉重复的 Cookie 探测搜索，并正确区分限流和空结果。
- 酷狗切换到证书正常的 HTTPS 搜索地址。
- QQ 两个搜索接口按固定顺序合并并按歌曲 ID 去重，避免响应先后顺序决定哪些版本进入候选范围。
- 来源下载按完成顺序交付，每个来源最多同时下载 4 个候选；取消搜索会取消剩余下载。临时断线、超时和部分服务端错误最多重试一次，限流不会立即反复请求。
- 自动每个来源、每个查询最多下载 40 个候选，手动最多 80 个；LRCLIB 展示接口返回的全部可用结果。自动与手动查询共享完整信息、标题变体和经过验证的跨语言别名。
- 新发现的本地语言歌名立即进入各来源的搜索队列，一个慢来源不会阻塞其他来源查询别名。自动等待上限 24 秒，手动上限 40 秒，超时保留已取得的结果。
- 自由输入其他关键词时，匹配分数相同的结果也遵循逐字、双语偏好及来源顺序。
- 搜索页展示各来源的结果数和错误状态，区分限流、证书异常、响应超时、数据格式异常与暂无结果。不同来源及不同版本 ID 不会因歌词正文相同被合并。重试同一查询时保留上次结果并标注。
- 逐字识别保留可用的单词、零时长字符、部分时间标记和重叠时间，只跳过无效时间片段；未标记的原文仍完整显示。LRCX 原始文字与时间标记继续保留。
- 网易云 YRC 分支合并对应翻译；近似时间戳采用一对一匹配，并根据相邻歌词间隔限制容差。

## 验证

离线回归覆盖空时长、坏记录隔离、超过 10 个候选、慢请求阻塞、取消下载、来源错误分别显示、相同正文不同版本、别名调度、逐字兼容和翻译合并。

默认离线回归测试通过，另外单独运行了下列联网测试。`In My Feelings` 连续三次搜索均得到 LRCLIB 22、网易云 53、QQ 4、酷狗 23 条相关结果，其中 6 条匹配目标歌曲，自动选中网易云双语版；两首此前报告的日语歌曲均自动选中双语逐字版本。

实测歌曲包括 `In My Feelings / Nerissa Ravencroft`、`DaiDaiDaiDaiDaikirai / amala`、`雪降り / AiSS & NE1516Hz` 及跨语言歌曲别名。联网结果属于测试时的来源快照，来源目录和服务状态仍可能变化。

```sh
swift test
LYRICSX_LIVE_SEARCH_RECOVERY=1 swift test --filter liveSearchRecoversAllSourcesAcrossRepeatedSearches
LYRICSX_LIVE_REPORTED_SONGS=1 swift test --filter liveReportedSongsAutomaticallyChooseBilingualWordLyricsWithoutCache
LYRICSX_LIVE_SOURCES=1 swift test --filter liveRomanizedSongResolvesAndSearchesNativeTitle
./scripts/build.sh release
```

## 安装

下载 `LyricsX-2.0.7.zip`，解压并将 `LyricsX.app` 拖到 `/Applications`。默认继续复用 LRCX 缓存；如要重新选择某首歌的歌词，使用搜索窗口或重新搜索命令。

此包使用 ad-hoc 签名，没有 Developer ID 公证。签名没有证书到期日，但不等于获得 Gatekeeper 信任。首次安装的系统提示与处理步骤见 [README](../../README.md#安装)。

原项目保留在 `Legacy/`，歌词依赖源码及原许可证保留在 `Vendor/LyricsKit/`，固定版本来源见其 `UPSTREAM.md`。
