# LyricsX 2.0.24

修复 Apple Music 封面缺失，以及应用新歌词后悬浮窗高度要等到下一句才更新的问题。

## 修复

- Apple Music 直接读取封面失败时，从系统媒体信息补读。补读前核对所属播放器、歌名、歌手和专辑，避免使用浏览器、其他播放器或上一首歌的封面。
- 封面暂时不可用时，前两次失败后间隔 3 秒重试，之后间隔 30 秒继续尝试；成功后复用封面缓存。切换歌曲会重置重试状态。
- 应用新搜索结果、手动替换歌词或更新同一文档时，立即重新计算悬浮窗高度。即使文档 ID 和当前行号没有变化，新增加的翻译、换行和连续追加文本也会参与排版。
- 清理被替换文档的旧增量文本排版缓存；正常逐字播放继续使用缓存，不逐帧重新测量。窗口顶部锚点、固定宽度、平滑缩放动画及原有歌词视图保持不变。
- 调整辅助文字间距时同步刷新窗口尺寸。

## 验证

- 204 项回归测试通过（串行执行）。
- 新增原生窗口测试：暂停状态下在当前句应用替换歌词；从等待状态自动加载；同一文档补充翻译和增量文本；恢复短歌词。验证窗口高度、顶部位置和宿主视图复用。
- 新增封面测试：播放器与歌曲身份隔离、父应用标识、Data URI，以及空数据、无效数据和过大数据的拒绝。
- 本机 Apple Music 与系统媒体信息身份匹配，系统回退路径返回了非空封面数据；这不代表所有曲目或第三方播放器均已实机验证。
- Release 构建完成，应用签名通过严格校验。
