# LyricsX 2.0.5

这是歌词源纯音乐占位文本识别的修复版本，目标系统为 macOS 26 及以上。

## 安装

下载 Release 中的 `LyricsX-2.0.5.zip`，解压后将 `LyricsX.app` 拖到 `/Applications`。已有歌词缓存不会由安装过程改写。

校验：`SHA-256 b25bfff8cc87f7d3e5c8f69589a7586cb660b9d925f0e6d1d7fc7edd4aefe9ea`。

本包使用 ad-hoc 签名，首次打开时如被 Gatekeeper 拦截：先在 Finder 中打开一次，然后到“系统设置 → 隐私与安全性”点击“仍要打开”。

## 修复

- 当歌词源把“纯音乐，请欣赏”等状态文本伪装成带时间轴歌词返回时，应用会识别它为无歌词状态。
- 仅在非空歌词不超过三行时匹配，覆盖简体/繁体中文、英文、日文、韩文及常见欧洲语言的纯音乐、无歌词、未填词和音符占位写法，避免误伤正常歌曲。
- 主窗口、菜单栏和悬浮窗都只显示歌曲名，不显示歌词源的状态文案。
- 自动搜索会先并发收集各歌词源前十个候选，再按严格匹配、逐字、双语和来源顺序确定最佳版本；避免先返回的普通结果抢先显示并写入缓存。
- 暂停、跳转和切歌时，单次播放器轮询失败会等待下一次快照确认，不再闪现“未识别到播放源”等错误；持续失败超过 1.25 秒才会显示提示。

## 验证

`swift test` 通过 75 项回归测试，覆盖短歌词占位识别、自动搜索候选深度和瞬态播放器错误抑制；Release 构建会执行严格签名校验。
