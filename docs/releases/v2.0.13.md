# LyricsX 2.0.13

维护者：Zikai Wang

悬浮歌词改为固定宽度、按换行调整高度，减少长短句之间的尺寸变化。修复主窗口歌词成为当前句时的位置跳动，并处理动画被切歌、隐藏或拖动打断后的状态问题。

## 固定宽度与自动高度

- “设置 → 悬浮窗 → 外观”提供“按歌词换行调整高度”。取消根据文字长度自动变宽、收窄以及最小宽度设置。
- 默认宽度为 620 pt。旧默认 520 pt 更新为 620 pt，其余已设置宽度保留。开启自动高度时禁止手动调整宽度；关闭该选项后可设置宽度，再重新开启。
- 长句及时增高；短句稳定约 0.65 秒后直接缩到当前所需高度。取消过长的收缩等待和沿用旧目标造成的多段收缩。短暂插入的短句和高速长短句交替不会反复改变高度。
- 增高约 0.34 秒，收缩约 0.48 秒，保持非线性平滑过渡。顶部和水平中心固定；靠近屏幕边缘时仍限制在可见范围内。
- 翻译、下一句按实际显示内容计算空间。“翻译或下一句”显示翻译时不再额外预留隐藏的下一句高度。翻译也支持双行；两行主歌词和辅助文字分别测量，底部保留适量空白与辉光空间，避免文字贴着玻璃底边。
- 连续追加文字继续预留完整前缀链的排版空间，保留增量显示。无歌词和纯音乐继续使用紧凑的歌曲信息卡片。

## 对齐与动画稳定性

- 修复主窗口歌词成为当前句时向左移动 12 pt 的问题：辉光绘制区域的补偿现在遵循文字的实际对齐方式。主窗口左对齐和悬浮窗居中排版分别验证。
- 逐字行在未活动与活动之间复用同一文字视图和绘制层，避免切换视图类型；逐字绘制不再叠加外层行动画引入的隐式动画。
- 未活动行走简单绘制路径，不处理逐字遮罩与辉光，也不启动连续帧更新。排版缓存和当前行的独立绘制时钟继续保留。
- 切歌入场动画取消后立即恢复静止状态；旧动画的完成事件无法终止新歌曲的入场动画。
- 拖动、隐藏和屏幕变更会正确取消窗口缩放。拖动结束后从实际窗口尺寸继续调整，避免停在中间尺寸或使用过期的目标位置。
- 换句、切歌、应用新歌词、翻译或下一句内容变化以及紧凑信息卡片切换时，统一提供非线性模糊过渡。新内容第一帧就从轻微模糊恢复清晰，始终只有一个前景内容层，玻璃和外框持续复用。
- 切歌模糊约 0.48 秒，普通内容变化最多约 0.36 秒，高速换句按实际间隔缩短。连续追加的文字保留局部动画，稳定的前缀不被整窗模糊反复影响。过渡结束、隐藏窗口和减少动态效果时停止额外帧更新。
- 保留下一句上移、平滑缩放、轻微回弹、模糊、逐字提亮与放大、长音辉光、HDR 亮度设置及减少动态效果。

## 验证

169 项测试通过，覆盖原有同步、搜索、缓存与交互回归，并验证：

- 单行、多行、左对齐与居中文字的活动状态像素位置，以及从右向左布局。
- 固定宽度下的增高、延迟收缩、连续短句防抖和增量歌词空间预留。
- 原生窗口缩放的中间帧：顶部、水平中心和宽度保持不变，承载歌词的视图身份与 bounds 不变。
- 缩放过程中开始拖动，松开后在新的顶部位置恢复目标高度。
- 辅助文字只保留实际需要的高度；旧句无残留、下一句衔接及两行主歌词与辅助文字分离。
- 320、620、1000 pt 宽度下的完整悬浮内容：两行主歌词、两行翻译、两行下一句均能显示，底部文字与边缘保持至少 20 pt 间距。
- 取消入场动画恢复静止，快速连续切歌不会被过期完成事件打断。
- 内容模糊曲线确为非线性，时间推进不会重新触发，增量追加不模糊已有内容，高速换句的过渡在下句前完成。

```sh
swift test
./scripts/build.sh release
```

这是针对已定位状态与排版问题的修复；实际动画帧率仍受设备和系统负载影响。

Release 构建、严格签名校验和安装后二进制一致性检查通过。安装后的原生窗口确认固定宽度选项、主窗口文字对齐、当前歌词与翻译排版及悬浮窗底部留白。

## 安装

下载 `LyricsX-2.0.13.zip`，解压并将 `LyricsX.app` 拖到 `/Applications` 替换旧版。现有缓存、歌词时间和偏好继续复用。保留一个应用安装副本，避免系统搜索出现多个版本。

本次沿用 ad-hoc 签名。首次打开提示的处理方式见 [README](https://github.com/wzk112/LyricsX#安装)。
