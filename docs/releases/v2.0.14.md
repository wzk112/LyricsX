# LyricsX 2.0.14

维护者：Zikai Wang

修正悬浮窗换句动画的作用范围，补上底部下一句的独立过渡，并处理切歌时短暂加载卡片造成的闪动和尺寸跳变。

## 换句与切歌

- 普通换句只更新歌词，标题和歌手保持稳定；手动应用其他歌词版本也只过渡歌词区域。
- 下一句从原预览位置非线性上移、放大，并在移动过程中带轻微模糊，完成后恢复清晰。只保留当前绘制层，旧句不排队等待退出动画。
- 底部的新下一句单独淡入、轻微上移并从模糊恢复清晰。变化的翻译使用同样的过渡；进入时间最长约 0.42 秒，高速歌词按实际间隔缩短。
- 继续保留增量追加、逐字提亮与放大、长音辉光、HDR 亮度、固定宽度与自动高度、顶部位置记忆及减少动态效果。
- 切歌加载使用最长约 0.16 秒的衔接：暂存一份完整画面并向模糊过渡，快速命中缓存时直接显示新歌词，避免中途闪过小加载卡片。快速连续切歌共用原截止时间，不延长旧画面的停留。
- 前奏、空行和只有省略号的间奏改为紧凑歌曲卡片；带有真实文字的省略号句子仍正常显示。封面与歌名、歌手作为整体居中。

## 窗口与性能

主窗口从开始最小化或关闭时就暂停连续歌词绘制和自动滚动；重新显示时直接定位到当前句。悬浮窗继续读取独立播放时钟，前奏转入第一句仍按准确的歌词边界唤醒。辅助文字共用已有歌词动画时钟，没有增加逐句任务或常驻定时器。
