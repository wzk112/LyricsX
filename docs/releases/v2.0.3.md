# LyricsX 2.0.3

这是针对无歌词展示的界面修复版本，目标系统为 macOS 26 及以上。

## 安装

下载 Release 中的 `LyricsX-2.0.3.zip`，解压后将 `LyricsX.app` 拖到 `/Applications`。已有歌词缓存不会由安装过程改写。

校验：`SHA-256 362d01375f8cf4ce34ae714f59c891a70a49b0579b2b92d7246cd5744710917f`。

本包使用 ad-hoc 签名，首次打开时如被 Gatekeeper 拦截：先在 Finder 中打开一次，然后到“系统设置 → 隐私与安全性”点击“仍要打开”。

## 修复

- 主窗口歌词区域在纯音乐、无可用歌词和正在搜索歌词时，统一只显示当前歌曲名。
- 不再显示“纯音乐，请您欣赏”“未找到歌词”等大段占位文案；手动搜索、导入和重新搜索功能仍可通过菜单栏和工具栏使用。
- 悬浮窗的行为不变：这些状态下继续自动隐藏，只有有效的非纯音乐同步歌词才显示。
