# LyricsX 2.0.23

自动模式限定为音乐播放器，并减少暂停与单播放器场景中的重复工作。

- 自动识别 Apple Music、Spotify、网易云、QQ 音乐及系统标记为音乐类的应用。根据所属应用标识判断来源，排除浏览器及其辅助进程，未知来源不按歌曲标题猜测。其他音乐应用仍需向 macOS 提供播放状态；未对所有第三方版本逐一实机验证。
- 浏览器接管系统播放后，不应用其元数据；使用通用播放控制前重新检查来源，避免旧按钮误操作浏览器。Apple Music、Spotify 仍保留专用模式。
- 仅运行一个 Apple Music 或 Spotify 时直接读取该播放器，跳过额外的系统来源查询进程。未发现音乐应用时不启动查询进程；应用启动和退出会触发更新。
- Apple Music／Spotify 暂停时兜底查询由每秒一次调整为每五秒一次。播放通知及用户操作仍立即触发读取；其他播放器保留原来的查询频率。
- 暂停时停止歌词时钟，由播放状态变化重新启动。正常播放时的逐字、模糊、辉光、玻璃及刷新率设置不变。
- 同一首歌复用内嵌歌词、文件位置等元数据；缓存应用类型判断，减少重复读取。

## 验证

199 项回归通过，新增覆盖音乐与浏览器来源规则、暂停查询间隔、通知刷新、歌词时钟的暂停和恢复。已在安装版自动模式下确认 Apple Music 的歌曲、封面及播放进度读取。

本次确认减少了特定路径的调用与唤醒次数，尚未得到可靠的逐应用瓦数或续航对比，不承诺固定的省电百分比。
