# LyricsX 2.0.11

维护者：Zikai Wang

主窗口与悬浮窗改用统一的柔和弹性动效，加入少量模糊，并修复重新打开应用后 Dock 隐藏设置可能失效的问题。

## 歌词动效

- 主窗口自动跟随歌词时使用轻微回弹，非当前行的缩放与模糊跟随同一节奏；手动浏览时保持文字清晰。
- 悬浮歌词轻轻向上滑入，模糊与透明度先恢复，再平滑落定。切换时只有当前歌词一个渲染层，避免上一句模糊残影叠在背后。
- 快速连续切句沿用正在显示的位置，避免每句重新向下跳动；原有逐字高亮、翻译和下一句显示方式保留。
- 切歌使用同一套短距离滑入；系统或应用开启“减少动态效果”时停止移动和模糊动画。
- 动效预览使用同一实现，保持独立于真实播放器与歌词缓存。

## Dock 显示

- 启动、重新打开和激活时都以保存的“在 Dock 中显示”为准，并在窗口激活处理后再次校正。
- 隐藏状态下以菜单栏应用方式启动，打开主窗口无需改变 Dock 偏好；重新开启该选项仍可立即恢复图标。
- 校正由生命周期事件触发，已处于正确状态时不重复修改；没有新增轮询定时器。

## 验证与安装

137 项测试通过，包含重新激活、延迟激活、偏好变化、任务取消和快速切句的回归。Release 构建、严格签名校验及安装后二进制一致性检查通过。macOS 27 实机验证了隐藏状态冷启动、Finder 再次打开、关闭主窗口后重新打开，以及 Dock 开关往返切换；独立动效预览可正常切句并保留逐字高亮。Spotlight 界面在测试环境未能启动，因此未将其列为已完成的实机验证。
