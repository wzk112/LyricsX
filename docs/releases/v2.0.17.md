# LyricsX 2.0.17

此次更新简化悬浮窗材质设置，修复原生玻璃的透明度调节，并整理歌词等待状态。

## 悬浮窗材质

- **Liquid Glass**：使用官方 `NSGlassEffectView.Style.clear`，保留背景纹理与折射，配合从顶部深色向下通透的渐变。
- **磨砂阅读**：使用官方 `.regular` 材质柔化后方细节，并保留更深的底色，照顾原文、翻译和下一句的可读性。

设置只保留这两种样式。可点击图例等宽排列，使用与实际悬浮窗相同的材质实现；移除了额外绘制的边缘遮罩，避免叠出一圈白线。

调节项改为“透明度”，范围收至 **20–80%**，数值越高越通透。渐变放在原生玻璃的 `contentView` 内，使两个样式都能可靠响应调节；不再把原生着色参数当作透明度。样式和数值会保存，旧背景浓度自动迁移到新范围。歌词文字和按钮不会随背景一起变透明。

原生材质仍由 macOS 决定最终光学效果。系统“降低透明度”开启时使用实色背景。高透明度在浅色或复杂背景上会降低对比度，可改用磨砂阅读。

## 等待歌词

加载歌词、前奏尚未开始、空白间奏或仅有省略号时，保留顶部歌名与歌手，正文显示三个小点。等待高度为 96 pt，宽度和顶部锚点保持稳定；确认无歌词或纯音乐时仍展示歌曲信息卡片。已经有可显示歌词时，后台继续搜索不会遮住歌词。

等待、歌词和歌曲卡片使用明确的显示状态，内容变化后重新计算高度。等待期间封面加载、搜索进度变化不会反复触发整窗切换动画。

## 验证

回归覆盖旧样式迁移、透明度保存与范围限制、等待时的标题和三个点、加载/正常歌词/间奏/搜索完成的尺寸切换、顶部锚点与宿主复用，以及既有歌词、搜索、缓存、逐字/HDR 和交互行为。原生材质另在浅色、深色和彩色背景上检查两种样式、透明度两端及两种控制条布局。

```sh
swift test --no-parallel
LYRICSX_CONTROL_QA=/tmp/lyricsx-glass-qa swift test --no-parallel --filter renderControlsOverLightAndDarkBackgrounds
./scripts/build.sh release
```

## 安装

下载 `LyricsX-2.0.17.zip`，解压后将 `LyricsX.app` 拖到 `/Applications` 替换旧版。缓存和偏好继续复用，沿用 ad-hoc 签名。首次打开提示的处理方式见 [README](https://github.com/wzk112/LyricsX#安装)。
