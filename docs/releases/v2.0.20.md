# LyricsX 2.0.20

显示能力改为明确标注“EDR 支持”，默认开启 HDR 辉光增强，并提高普通亮度下长音辉光的可见度。

- **EDR 支持**：逐屏显示 macOS 报告的扩展亮度能力，不按电脑型号屏蔽，不将 EDR 结果视为 XDR 等级或固定峰值亮度认证。详细余量放在“开发者选项 → 显示诊断”。
- **默认开启增强**：新用户默认开启 HDR 辉光增强，手动关闭后会记住选择；升级保留已保存的开关值。
- **按窗口输出**：主窗口与悬浮窗各自使用所在屏幕的能力，目标亮度限制在该屏幕潜在余量内。普通屏幕自动使用普通辉光，保留开关偏好。
- **普通辉光更明显**：略微加宽并加深长音光晕，保持原有渐进出现、消退、逐字与位移动画，继续复用现有绘制层。

## 验证

回归测试覆盖默认值与手动关闭的持久化、尚未激活 EDR 时的能力判断、无效亮度值、普通亮度回退，以及浮点渲染中的扩展亮度上限。另输出普通辉光对比图检查可见度和文字排版。

```sh
swift test --no-parallel
./scripts/build.sh release
```

## 安装

下载 `LyricsX-2.0.20.zip`，解压后将 `LyricsX.app` 拖到 `/Applications` 替换旧版。沿用 ad-hoc 签名；首次打开提示的处理方式见 [README](https://github.com/wzk112/LyricsX#安装)。
