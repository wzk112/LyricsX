# LyricsX 2.0.18

悬浮窗新增磨砂调节，改善玻璃边缘与内部渐变；歌词动效跟随当前屏幕的最高刷新率，隐藏内容停止逐帧绘制。

- **磨砂程度**：在设置的悬浮窗外观中调节 0–100% 的背景柔化程度。两种样式分别保存，切换或重启后恢复。0% 仍保留原生材质本身的效果，歌词文字保持清晰。
- **Liquid Glass**：加宽保留原生光学效果的外围过渡带，平滑衔接中央磨砂，避免固定高光描边。玻璃内部采用顶部较深、向下逐渐通透的黑色渐变；改变磨砂时补偿暗色浓度。
- **磨砂阅读**：降低暗色渐变，提高少量实际透明度，保留比 Liquid Glass 更强的背景柔化。透明度越高，背景越通透。
- **尺寸切换**：材质和阅读遮罩各自跟随实际视图尺寸更新，避免从紧凑卡片展开后留下横向明暗分界。
- **屏幕刷新率**：解除歌词绘制的 60 Hz 上限，主窗口、悬浮窗和动效预览根据各自所在屏幕请求最高刷新率；移动到其他屏幕或调整屏幕配置后更新。实际帧率仍受 macOS 电源、温度与显示设置影响。
- **性能**：鼠标经过隐藏悬浮窗时，停止其中的逐帧绘制。复用有上限的遮罩缓存，避免重复设置相同原生材质、挂载遮罩和上传图像；尺寸未变时跳过遮罩布局。减少逐字绘制的重复排序与辅助文字的逐帧尺寸查询，保留原有辉光、HDR、模糊与弹性动效。

保留两张等宽对齐的样式图例和 20–80% 的透明度调节。位置、歌词动效和 HDR 继续沿用。复用单个原生玻璃视图，边缘遮罩共享缓存并随窗口缩放；不新增定时器，也不采集屏幕制作玻璃。官方没有提供独立的折射强度或模糊半径参数，磨砂通过原生材质的混合程度调节。

## 验证

189 项回归测试通过；原生窗口测试在 120 Hz 屏幕上测得约 120 次刷新回调/秒，验证主窗口最小化、关闭不停止悬浮窗回调，以及鼠标经过隐藏后停止逐帧绘制。使用独立进程提供浅色、深色、彩色和文字背景，检查两种材质、透明度与磨砂两端、内嵌和独立控制条以及 HDR 开关。通过像素检查验证背景细节能透出、磨砂滑块能实际柔化背景、窗口缩小再展开后渐变没有断层，并验证每种样式的偏好在重启后恢复。

```sh
swift test --no-parallel
LYRICSX_CONTROL_QA=/tmp/lyricsx-glass-qa swift test --no-parallel --filter renderControlsOverLightAndDarkBackgrounds
./scripts/build.sh release
LYRICSX_WINDOW_QA=1 swift test --no-parallel --filter WindowFrameTests
LYRICSX_PERFORMANCE_QA=1 swift test -c release --no-parallel --filter animatedSurfacesStopWorkWhenHiddenAndKeepNativeCadence
```

## 安装

下载 `LyricsX-2.0.18.zip`，解压后将 `LyricsX.app` 拖到 `/Applications` 替换旧版。缓存和偏好继续复用，沿用 ad-hoc 签名。首次打开提示的处理方式见 [README](https://github.com/wzk112/LyricsX#安装)。
