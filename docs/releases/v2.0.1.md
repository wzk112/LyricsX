# LyricsX 2.0.1

这是 2.0.0 的稳定性修订版，目标系统为 macOS 26 及以上，并针对 macOS 27 的网络异常进行了修复。

## 安装

下载 Release 中的 `LyricsX-2.0.1.zip`，解压后将 `LyricsX.app` 拖到 `/Applications`。已有歌词缓存不会由安装过程改写。

校验：`SHA-256 3ffac4866920c64ddb61447e0cc0269336d74296e453e184346a7a7c60a1fc50`。

本包使用 ad-hoc 签名，首次打开时如被 Gatekeeper 拦截：先在 Finder 中打开一次，然后到“系统设置 → 隐私与安全性”点击“仍要打开”。

## 修复

- 新搜索和自动缓存恢复为 `.lrcx`，逐字时间、翻译、偏移及来源附加信息都会保留。
- `.lrc` 和纯文本歌词仍可导入和读取；已有文件被实际加载后会在原位置更新，避免重复缓存。
- Apple Music 仍是当前歌曲封面的唯一播放源。QQ 音乐仅用于歌词搜索，已跳过其无关的歌词条目封面请求。
- 替换会触发 macOS 27 CFNetwork 异常的 `URLSession.data(for:)` 调用，并在所有请求进入网络层前校验协议、主机和 URL。
- 拖动进度时，Apple Music 短暂返回的空元数据不再清空当前歌曲和歌词；播放器确认新状态后才会更新界面。
- 当所有严格候选都因歌词源的错误时长被过滤时，自动搜索会回退到歌名、歌手完全匹配的同步歌词；严格匹配结果始终优先。

## 清除旧缓存后重新获取

关闭 LyricsX 后，删除缓存目录中的歌词文件，再播放或搜索歌曲即可生成新的 `.lrcx` 缓存。默认目录为 `~/Music/LyricsX`；如果你在设置中选择了其他目录，请清除那个目录中的歌词文件。
