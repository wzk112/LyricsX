# LyricsX 2.0.9

维护者：Zikai Wang

手动搜索增加默认关闭的“完整搜索”开关。默认精简搜索从请求量、查询深度、去重和匹配展示四层减少无关结果；需要查阅所有版本时仍可切换到完整搜索。

## 手动搜索

- 精简模式默认启用，仍覆盖全部已启用歌词源。
- 每个来源先查询完整歌曲信息和原始标题；标题包含 `feat.`、`Full Version` 等修饰时，再查询一个清理后的标题。
- 每个来源、每个查询最多下载 12 个候选，最多显示 12 个可信版本，最长等待 18 秒。
- 同一来源中歌词内容、时间轴和翻译完全相同的副本会合并，不再因为版本 ID 不同重复占据列表。
- 搜索当前歌曲时，只显示达到严格可信阈值的版本；即使设置中关闭“严格匹配”，同名翻唱和歌手不符的低分宽松结果也不会混入精简列表。它们仍留在内部候选中，如果后续确认跨语言别名，会重新评分并正常进入列表。自由输入其他关键词时不套用当前歌曲过滤。
- “完整搜索”打开后，展开全部标题及经过验证的跨语言别名，每个查询最多下载 80 个候选，最长等待 40 秒，并保留不同版本 ID。
- 切换搜索模式会重新开始对应深度的搜索并清空另一种模式的旧列表，避免完整搜索结果残留在精简模式中。

## 验证

离线回归覆盖四个来源的精简上限、完整模式版本保留、相同正文去重、当前歌曲错配过滤、自由关键词不过滤，以及自动搜索、缓存和悬浮窗原有回归。

联网使用 `In My Feelings / Nerissa Ravencroft` 验证：精简模式显示 3 个可信版本，包括 LRCLIB 两个版本和网易云双语版本，约 7.0 秒完成；没有可信匹配的来源显示 0 个版本。联网结果会随歌词源状态变化。

```sh
swift test
./scripts/build.sh release
```

## 安装

下载 `LyricsX-2.0.9.zip`，解压后将应用拖到 `/Applications` 替换旧版。无需清空歌词缓存。

使用 ad-hoc 签名，没有证书到期日，也没有 Developer ID 公证。首次打开的系统提示与处理方法见 [README](https://github.com/wzk112/LyricsX#安装)。
