# LyricsX 2.0.21

修复悬浮窗偶发的上方留白与底部裁字，并恢复带首尾空白的外语歌词从下一句上移的动画。

- **文字与高度一致**：测量与实际绘制使用相同的可用宽度，避免临界长度的一行歌词被误算成两行，导致文字下移、顶部多出一行空白。
- **切换不裁字**：旧歌词退出期间，窗口按实际显示的内容保持空间，退出完成后再进入紧凑等待状态。后续高度仍以原来的非线性动画变化，顶部位置和文字宿主保持稳定。
- **多语言换句**：预览会移除首尾空白，原歌词保留空白以维持逐字时间位置。现在按去除首尾空白后的内容判断是否为同一句，避免外语歌词失去预览上移动画。辅助文字模式不变。
- **帧率选项**：“设置 → 动效”增加“悬浮窗帧率”，可选“跟随屏幕”或“60 帧”，保存后下次启动继续生效。默认继续跟随屏幕；主窗口独立刷新，所有歌词动效保留。
- **合成整理**：移除悬浮歌词外层重复的合成分组，辉光改为直接绘制字形，减少一次中间字形遮罩；保留文字阴影、长音辉光、EDR 和玻璃材质。

## 性能测试

使用独立原生窗口、固定宽度、相同测试歌词与动效，在 120 Hz 屏幕上交替运行 120/60 帧，并对照隐藏状态。未控制真实播放器或改写真实歌词缓存。

一轮测试中，渲染进程 CPU 平均约为 13.8%（120 帧）与 8.4%（60 帧）。整机 GPU 活跃率平均约为 49.4% 与 49.0%；隐藏测试窗口时仍约为 42.6%，存在其他应用和窗口合成负载。本轮无法将 GPU 变化可靠归因于 LyricsX，也不能据此推算整机省电百分比。详细测试方法见 [性能记录](../performance/overlay-2.0.21.md)。

## 验证与安装

195 项回归及 3 项原生窗口测试通过。回归覆盖截图中的临界长句、两行到等待状态的原生窗口切换、多个语言的首尾空白、帧率选择持久化和跨窗口刷新隔离。

```sh
swift test --no-parallel
LYRICSX_WINDOW_QA=1 swift test --no-parallel --filter WindowFrameTests
./scripts/build.sh release
```

下载 `LyricsX-2.0.21.zip`，解压后将 `LyricsX.app` 拖到 `/Applications` 替换旧版。首次打开说明见 [README](https://github.com/wzk112/LyricsX#安装)。
